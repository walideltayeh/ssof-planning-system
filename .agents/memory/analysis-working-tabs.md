---
name: Analysis working tabs
description: User-required distinction between daily Analysis navigation and board presentation
---

Analysis uses five working tabs: Summary, Demand, Supply & Stock, Quality & Risk, Value. Only the selected group's content should mount during ordinary browsing. Remember the last selection per user; default to Summary when none exists. Keep Deep Dive collapsed at the bottom.

**Why:** The user said the long stacked page and section shortcut grid made Analysis hard to navigate.

**How to apply:** Do not use the selected working tab or group order to change Presentation Mode or PDF. Those retain the complete saved/default board sequence, excluding the removed dedicated FOC section. Country permissions and the shared Include FOC basis still apply.
