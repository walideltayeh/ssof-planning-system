name: Analysis working tabs
description: User-required distinction between daily Analysis navigation and board presentation
---

Analysis uses six working tabs: Summary, Demand, Supply & Stock, Quality & Risk, Value, Monthly Analysis. Only the selected group's content should mount during ordinary browsing. Remember the last selection per user; default to Summary when none exists. Keep Deep Dive collapsed at the bottom.

**Why:** The user said the long stacked page and section shortcut grid made Analysis hard to navigate.

**How to apply:** Do not use the selected working tab or group order to change Presentation Mode or PDF. Those retain the complete saved/default board sequence, excluding the removed dedicated FOC section. Country permissions and the shared Include FOC basis still apply.

Monthly Analysis is a dense planner workspace for building the forecast, not a board presentation. Suggestions are read-only comparisons, never forecast writes. Keep it entirely out of slide order and the board PDF, for Lebanon and international countries alike.

**Why:** The user explicitly distinguished the planner's month-by-month working view from the board view and required the trusted Running Rate and Stock Levels basis.

**How to apply:** Preserve shared stock and per-SKU running-rate methods instead of introducing competing metrics. Show missing history and thin seasonal samples explicitly; do not treat auto-filled IMS as actual sales.
