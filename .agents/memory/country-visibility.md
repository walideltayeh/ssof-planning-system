---
name: Country hiding and restoration
description: User-approved scope for reversible country availability and Admin restoration.
---
Hiding a country makes it unavailable to everyone, including the owner and already signed-in users. Remove it from country selection and switching, and enforce the restriction on the server rather than only hiding navigation.

**Why:** The user explicitly chose “Everyone” when asked who should lose access.

**How to apply:** Preserve all saved country records, history and user assignments. Keep Admin country management reachable even when every country is hidden so restoration never requires selecting an available country. This is Hide/Restore, not permanent data removal.
